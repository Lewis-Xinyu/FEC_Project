## 指标说明

- `PQ = SQ * RQ`
- `SQ` 表示 `IoU >= 0.5` 的一对一匹配实例的平均 IoU。
- `RQ = TP / (TP + 0.5 FP + 0.5 FN)`。
- `RC50 = TP / (TP + FN)`，匹配阈值为 `IoU >= 0.5`。
- `mIoU` 表示所有 GT 实例与预测簇最佳重叠 IoU 的平均值。
